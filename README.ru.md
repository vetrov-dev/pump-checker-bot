# Pump.fun checker bot

Telegram-бот, который проверяет монеты Pump.fun перед покупкой. Он не торгует, не держит деньги и никогда не
просит приватный ключ.

## Что умеет

| Команда | Что делает |
|---|---|
| Адрес или ссылка на монету, `/check` | Платформа, статус (кривая или PumpSwap), капитализация и ликвидность, может ли создатель выпускать или замораживать монеты, топ-холдеры, доля дева, бандл в блоке запуска и снайперы в следующих двух блоках, держат ли ранние кошельки до сих пор, история дева, соцсети, платное продвижение на DexScreener. В конце **траст 0–100** с разбором, за что сняты баллы |
| Адрес кошелька, `/dev` | Сколько монет запускал, сколько вышло на PumpSwap, быстрые сливы, медианный пик, последние 10 запусков |
| `/watch <кошелёк> [метка]` | Пишет в личку о запусках, покупках и продажах кошелька и о выходе его монет на PumpSwap |
| `/list`, `/unwatch` | Список слежек и удаление |
| `/alerts` (Pro) | Алерт, когда монету запускает дев, у которого ≥50% прошлых монет вышли на PumpSwap и не больше 5 запусков за сутки |
| `/pro` | Подписка за Telegram Stars |
| `/paysupport`, `/terms` | Поддержка по оплате и условия (Telegram требует их для ботов со Stars) |
| `/stats`, `/grant <id> <дней>`, `/refund <id> <charge_id>` | Только для админов из `ADMIN_IDS` |

Ссылки принимаются с pump.fun, Axiom, GMGN, Photon, BullX, DexScreener и solscan, с адресом монеты или пары.

**Какие монеты:** Pump.fun разбирается полностью. Монеты с других площадок (LetsBonk, Meteora, Raydium, Moonshot
и т.д.) получают общие проверки: права создателя, холдеры, ликвидность, соцсети. Дева и бандл бот определяет пока
только на Pump.fun.

### Траст

Старт со 100 баллов, каждый риск снимает баллы, хорошая история дева добавляет 10.

| Риск | Баллы |
|---|---|
| Создатель может выпускать новые монеты / замораживать кошельки | −40 / −40 |
| Бандл в блоке запуска ≥40% / ≥15% / ≥5% | −40 / −25 / −10 |
| Топ-10 холдеров ≥50% / ≥30% / ≥20% | −30 / −15 / −5 |
| Дев держит ≥10% / ≥5% | −25 / −10 |
| Дев сливал покупку в первые 10 минут в половине своих монет | −25 |
| Ликвидность меньше $5K / $20K (вне кривой) | −15 / −5 |
| Нет данных о холдерах (уровень тогда не выше «средний») | −15 |
| Один кошелёк ≥10%, ранние кошельки держат ≥5%, дев продал ≥90% покупки, >5 запусков дева за сутки, нет соцсетей | −10 каждый |
| Монете меньше 5 минут, режим Mayhem, ликвидность меньше $20K | −5 |

Уровни: 80–100 высокий 🟢, 60–79 средний 🟡, 40–59 низкий 🟠, 0–39 очень низкий 🔴. Шкала рассчитана на мемкоины:
у USDC, например, будет 0, потому что эмитент может выпускать и замораживать монеты.

Бесплатно: 5 проверок в день и 1 кошелёк. Pro: 300 проверок, 20 кошельков и алерты. Всё меняется в `.env`.

## Откуда данные

- **PumpPortal, бесплатно:** все запуски и миграции. Из них строится база девов.
- **Solana websocket:** сделки (слежка, продажи дева, пики). Публичный видит только часть сделок, поэтому лучше свой `WS_URL`.
- **Solana RPC:** кривая, холдеры, первые блоки. Публичный RPC не отдаёт холдеров (`getTokenLargestAccounts`), для них нужен `RPC_URL` с ключом.
- **DexScreener, бесплатно:** капитализация, ликвидность, соцсети, оплаченные профили и бусты.

База (`data/bot.db`) копится, пока бот работает. Чем дольше он работает, тем полезнее `/dev`.
Старые записи из sol_scalper уже загружены: 58 тыс. запусков с 27.10.2026. Повторить загрузку:
`python seed.py ../sol_scalper/data`.

## Запуск на своём ПК (проверка)

1. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN` и `ADMIN_IDS`.
2. Запустите `run.bat`.

Проверка без Telegram: `.venv\Scripts\python.exe bot.py check <адрес монеты>`.

## Запуск на сервере (чтобы ПК не держать включённым)

Подойдёт самый дешёвый VPS с Ubuntu 24.04, например Hetzner CX22 (~€4.5 в месяц).

```bash
# на сервере, под root
adduser --disabled-password --gecos "" bot
apt update && apt install -y python3-venv
```

С ПК скопируйте папку (без `.venv`), вместе с базой:

```bash
scp -r pump_alerts root@IP_СЕРВЕРА:/home/bot/
```

Дальше на сервере:

```bash
chown -R bot:bot /home/bot/pump_alerts
cd /home/bot/pump_alerts && rm -rf .venv
sudo -u bot python3 -m venv .venv && sudo -u bot .venv/bin/pip install -r requirements.txt
nano .env              # проверить токен и настройки
cp deploy/pump-alerts.service /etc/systemd/system/
systemctl enable --now pump-alerts
journalctl -u pump-alerts -f     # логи
```

Бот сам перезапускается после падения и после перезагрузки сервера.

## Честные ограничения

- `/dev` знает только монеты, которые бот видел с 27.10.2026. Если дев сменил кошелёк, бот его не свяжет.
- На публичном websocket часть сделок теряется: продажи дева и пики могут быть занижены.
- Бандл считается по первому блоку кривой. Для монет больше чем с 3000 сделок первые блоки не разбираются.
- Алерты о «хороших девах» — не сигнал на покупку. В наших бэктестах покупка на старте в среднем была убыточной, и бот так и пишет.
